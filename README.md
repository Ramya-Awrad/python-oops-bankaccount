# Python OOP Bank Account System

This project demonstrates **Object-Oriented Programming (OOP)** concepts in Python by implementing a simple **Bank Account system with an ATM-style menu**.

The program allows users to log in using their **account name and PIN** and perform basic banking operations such as checking balance, depositing money, withdrawing money, and viewing transaction history.

---

## Features

* Secure login using account name and PIN
* Check account balance
* Deposit money
* Withdraw money
* Transaction history tracking
* Simple ATM menu interface

---

## OOP Concepts Used

* Classes and Objects
* Encapsulation (private balance variable)
* Methods
* Object interaction

---

## Project Structure

```
python-oops-bank-system
```
